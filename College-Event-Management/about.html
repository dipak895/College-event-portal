About the Project

The College Event Management Portal is a responsive website developed as an internship project. It lets students view college events, read notices and register for upcoming events. It is a front-end project built using HTML5, CSS3, vanilla JavaScript and Bootstrap 5, and event data is stored in JavaScript arrays.

Project Objective

The objective is to give students a simple, single platform to find event information and notices, and to register for events online, while demonstrating core front-end skills: page structure, styling, responsive design, DOM manipulation and form validation.

Project Details

  • Responsive design for desktop, laptop, tablet and mobile
  • Event cards with date, time, venue and description
  • Search events and filter them by category
  • Event details shown in a pop-up window (modal)
  • Notice board with category badges and search
  • Registration and contact forms with JavaScript validation
  • Image carousel on the home page
